## 1. 목적

적대적 입력 detector의 임계값을 산출하기 위한 표본을 모은다. 현재 표본은 단일
피험자·단일 세션·단일 공격 종류이며, 이 촬영으로 세 한계를 함께 해소한다.

## 2. 수집 방식

원격 참가자는 Colab 노트북을 사용한다. 얼굴 영상 파일을 만들어 주고받지 않는다.
촬영본이 전송 채널에 남으면 `11_SECURITY_ETHICS_AND_LIMITATIONS.md`의 최소 수집
원칙과 `EXP-PAD-001`의 동의·보관 조건을 어긴다.

```text
https://colab.research.google.com/github/Yaho03/26_HC160/blob/experiment/EXP-DET-001-camera-squeeze-probe/notebooks/colab_probe_capture.ipynb
```

브라우저에서 촬영한 프레임은 Colab 임시 런타임 메모리에서 처리되고 파일로 저장되지
않는다. 참가자가 내려받는 것은 `probe.csv`와 `session.json`뿐이며 숫자와 익명 라벨만
들어 있다.

## 3. 참가자 라벨

| 라벨 | 대상 |
|---|---|
| `p01` | 로컬 (이미 수집 완료: 세션 `7b94fe4d1971`) |
| `p02` | 원격 참가자 1 |
| `p03` | 원격 참가자 2 |

라벨과 실명의 대응은 저장소에 기록하지 않는다. 필요한 경우 저장소 밖에서 관리하고
분석이 끝나면 폐기한다. `subject_id`는 영문자·숫자·하이픈·밑줄만 허용하며 이름과
이메일은 코드가 거부한다.

## 4. 세션 구성

참가자당 두 세션을 찍는다. 세션 사이에 조명을 바꾼다.

| 세션 | 조명 | 목적 |
|---|---|---|
| 1 | 밝은 곳 (창가 또는 조명 켠 상태) | 기준 조건 |
| 2 | 어두운 곳 (조명 일부만) | 조명 변화 반영 |

세션당 `TARGET_FRAMES = 200`, `ATTACK_EVERY = 5`이므로 clean 200개와 adversarial
40개가 모인다. 공격은 `pgd`, `fgsm`, `pgd_low_eps` 세 종류를 번갈아 생성한다.

## 5. 촬영 중 지켜야 할 것

**가만히 응시하지 않는다.** 이것이 가장 중요하다. 정지 상태로 찍으면 clean 표본의
분산이 실제보다 작아지고, 그 데이터로 정한 임계값은 오탐률을 과소평가한다.

촬영 중 다음을 계속 바꾼다.

- 고개 각도. 좌우와 위아래로 조금씩
- 표정. 무표정, 미소, 말하는 동작
- 카메라와의 거리. 조금 가까이, 조금 멀리
- 안경 착용자는 중간에 벗었다 쓰기

얼굴은 화면 안에 계속 보여야 한다. 얼굴이 잡히지 않은 프레임은 표본으로 세지 않는다.

## 6. 품질 자가 검사

노트북의 6.5단계가 데이터를 자동으로 검사한다. 실패가 나오면 참가자가 아직 앉아
있는 동안 다시 찍는다. 나중에 발견하면 다시 부탁해야 한다.

| 검사 | 기준 | 실패 의미 |
|---|---|---|
| `jpeg_headroom_q75` | 1.0 이상 | 입력이 이미 압축됨. JPEG 계열 변환의 탐지력이 사라진다 |
| 얼굴 검출률 | 50% 이상 | 조명 부족 또는 화면 밖으로 벗어남 |
| 자기상관 | 0.60 미만 | 정지 상태. 인접 프레임이 거의 같다 |
| 인접 변화량 비율 | 0.30 이상 | 정지 상태 |
| clean 표본 수 | 100개 이상 | 목표 FPR 1%를 관측값으로 맞출 수 없다 |

움직임 판정은 절대값이 아니라 시계열 구조로 한다. 특정 세션의 변동계수를 기준으로
삼으면 그 세션이 좋았는지 알 수 없는 순환 논리가 된다.

참고값은 로컬 세션 `7b94fe4d1971`에서 측정했다. 자기상관 +0.121, 인접 변화량 0.73,
`jpeg_headroom_q75` 2.20.

## 7. 수집 후 확인

원격 세션과 로컬 세션을 합치기 전에 `jpeg_headroom_q75`를 비교한다. Colab은 브라우저
PNG 캡처, 로컬은 OpenCV 직접 캡처이므로 입력 특성이 다를 수 있다. 값이 크게 다르면
합치지 않고 출처를 변수로 분리해 보고한다.

`07_DEFENSE_AND_DETECTION_SPEC.md` 5절은 subject와 session 분리를 요구한다. 임계값은
clean 표본만으로 정하고, 최종 평가는 캘리브레이션에 쓰지 않은 참가자로 한다.

## 8. 개인정보

기록되는 것은 코사인 유사도 등 숫자, 익명 라벨, 카메라 해상도와 처리 속도다.
기록되지 않는 것은 얼굴 사진과 영상, 얼굴 특징 벡터, 이름과 연락처, 절대 경로다.
`probe_log.py`가 절대 경로와 생체 원본을 산출물에서 거부한다.

수집한 CSV는 `outputs/probe/`에 두며 `.gitignore`로 저장소에서 제외한다. 참가자가
요청하면 해당 세션 디렉터리를 삭제한다. 세션마다 provenance가 분리 기록되므로 세션
단위 삭제가 가능하다.
